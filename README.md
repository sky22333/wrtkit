# WrtKit

WrtKit 是一个面向 ImmortalWrt ImageBuilder 的本地可视化固件构建工具。前端为中文界面，使用 Go、Gin、SQLite、React 和 Ant Design；前端资源在编译时嵌入可执行文件。

> 当前为开发预览版。已在 Windows 的 WSL Containers 3.0.3 上实际构建 x86/64 的 23.05.4 和 25.12.2；使用隔离根文件系统测试了 23.05.7、24.10.6 和 25.12.2 的软件源初始化和索引更新。尚未完成实机启动和完整版本、设备矩阵验证。

## 开始使用

需要 Go 1.26、Node.js 24 及 npm。Windows 使用支持容器的 WSL 和 `wslc.exe`；Linux 需要可访问 Docker Engine 的 Unix socket。

```powershell
cd web
npm ci
npm run build
cd ..
go build -o dist/wrtkit.exe ./cmd/wrtkit
.\dist\wrtkit.exe
```

Linux 将最后两行改为 `go build -o dist/wrtkit ./cmd/wrtkit` 和 `./dist/wrtkit`。浏览器访问 <http://127.0.0.1:8088>。可使用 `-addr` 和 `-data-dir` 指定监听地址和数据目录；管理服务没有用户认证，务必只监听本机。构建记录、日志、配置和固件保存在数据目录，默认是当前目录下的 `data`。记录可能包含用户填写的初始化脚本，请自行妥善保护数据目录。

系统环境页可发起 WSL 安装请求；该操作由系统处理，可能需要管理员确认或重启。WSL 版本必须包含 `wslc`，安装 WSL 并不保证系统立即具备可用的容器运行时。参见 [Microsoft WSL 容器文档](https://learn.microsoft.com/en-us/windows/wsl/wsl-container)。

## 已实现

- 从用户选择的镜像站读取版本、设备与设备配置；软件源站页面以名称和地址管理完整的可选列表，第一项为默认源。CERNET 和 Vsean 可能重定向到其他镜像站。
- 构建前确认设备存在、获取 Docker Hub 镜像摘要并固定；容器启动时比对 ImageBuilder 与镜像站的版本修订号。
- 首次启动时将所选镜像写入 opkg 或 apk 软件源配置，以及 ImmortalWrt 的相应持久化设置。自定义脚本可再次修改。
- 软件页统一展示上游设备清单的默认包和已选包；以浅色区分内置项，推荐包仅在当前索引可用时预选。预选翻译包可能通过依赖安装对应插件。
- 默认勾选 LuCI 简体中文基础语言包，并按照当前镜像索引自动匹配已选 LuCI 插件及主题的中文翻译；匹配采用常见命名约定，缺失时提示。
- 选择设备，优先从该版本的 feeds.conf 发现软件源，按架构加载软件包索引，较新版本还按上游内核标识加载 kmods；支持按全部、LuCI 界面、主题及代理工具分类搜索。代理分类展示实际索引中的 LuCI 应用，按包名推断类别，可能漏报或误报，并不是上游提供的类别；依赖能否满足以构建结果为准。
- 从所选软件源读取 LuCI 主题（默认 Argon），填写管理员密码、LAN、无线和 PPPoE 等快捷配置；磁盘镜像设备可设置根分区大小。支持可选的 `uci-defaults/99-custom.sh`。
- 管理员密码哈希写入固件；快捷配置中的密码不保存在任务数据库，但 Wi-Fi 和 PPPoE 凭据必须包含在生成的固件中，应保护构建产物。
- 构建任务、日志、取消、历史记录、固件下载；SQLite 本地存储。
- Linux Docker Engine Unix socket 与 Windows `wslc` 容器适配的初步实现；使用容器文件复制或归档传递文件。
- ImageBuilder 默认从 Docker Hub 拉取；设置中可填写单个 HTTPS 镜像仓库前缀，拉取时保留 Docker Hub 返回的摘要，不自动回退。解析摘要仍需访问 Docker Hub；应用内不缓存软件包文件。
- 历史记录可预览并清理单次构建的产物和已标记容器；仅在可确认由本工具拉取且没有其他记录引用时删除 ImageBuilder 镜像，保留任务记录和日志。旧记录无法确认镜像归属，因此保留镜像。

## 尚未完成与已知限制

- Linux Docker 与其他 Windows、WSL Containers 版本、硬件平台尚未完成实际固件构建和启动测试；不能保证所有版本和设备都可用。
- 软件包索引由所选镜像站提供；部分软件源不可用时会提示，手动输入的包需由构建过程验证。
- 可手动切换镜像站；没有实现构建中自动故障切换及软件源索引完整性锁定。
- ImmortalWrt 官方下载源可手动选择；其他部分自托管服务仍被拒绝。容器网络和重定向没有强制隔离，因此即使选择第三方源，**尚不能保证完全避免访问上游服务器**。
- 快捷配置尚未涵盖 KWRT 的完整功能。上游设备资料没有可靠的无线和 WAN 能力字段；无线输入按所选包中的已知无线驱动推断，无法识别时隐藏，可能漏报。PPPoE 在首次启动时检查 WAN 配置，不存在则跳过；根分区支持根据设备镜像格式推断，需在目标设备实测。
- 分支快照候选由稳定版本的分支推导，并检查镜像站是否存在设备总览；Docker Hub 镜像在构建前检查。主题资源路径由包名推断，目录不匹配时不会强制切换主题。
- 本服务为单用户本机工具，未提供认证，不适合直接暴露到局域网或公网。
